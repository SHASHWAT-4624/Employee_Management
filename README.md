# Employee Management System

A full-stack web application built to manage employee records, positions, and details efficiently. 

---

## 🚀 Features
* **View Employees:** Display a complete list of all registered employees.
* **Add Employees:** Insert new employee records into the database.
* **Update / Edit:** Modify existing employee details.
* **Delete:** Remove employee records from the system.
* **Responsive UI:** Clean interface built using HTML, CSS, and Thymeleaf templates.

---

## 🛠️ Tech Stack
* **Backend:** Java 21, Spring Boot, Spring Data JPA / Hibernate, Thymeleaf
* **Database:** MySQL (Hosted on Clever Cloud)
* **Hosting / Deployment:** Render (Backend & Application Server)
